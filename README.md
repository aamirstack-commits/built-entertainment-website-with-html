# 🎬 Entertainment Website

A modern, responsive entertainment website built with HTML, and CSS. This project showcases movies, TV shows, and entertainment news with a clean and user-friendly interface.

## 🚀 Live Demo

Check out the live website: [Entertainment Website](https://built-entertainment-website-with-ht.vercel.app/)

## ✨ Features

- 📱 Fully Responsive Design - Works seamlessly on desktop, tablet, and mobile devices
- 🎨 Modern UI/UX - Clean and intuitive interface with smooth animations
- 🎬 Entertainment Content - Movies, TV shows, and entertainment news
- 🌙 Dark Theme - Eye-friendly dark mode design
- ⚡ Fast Loading - Optimized for performance
- 🔍 Easy Navigation - User-friendly menu and layout

## 🛠️ Technologies Used

- HTML5 - Semantic markup and structure
- CSS3 - Styling, animations, and responsive design
- Vercel - Deployment and hosting

## 💻 Installation & Setup

1. Clone the repository
   git clone https://github.com/yourusername/entertainment-website.git

2. Navigate to project directory
   cd entertainment-website

3. Open in browser
   Simply open index.html in your preferred browser or use Live Server in VS Code
